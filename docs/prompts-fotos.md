# Prompts para las fotos de la carta

95 platos y bebidas sin foto. Para cada uno:

1. Copia el prompt en ChatGPT (o Gemini) y pide la imagen.
2. Guárdala con el **nombre de archivo** indicado (vale .jpg, .png o .webp) en una carpeta, p. ej. `~/fotos-carta`.
3. Cuando estén todas (o algunas): `npm run fotos -- ~/fotos-carta` → se optimizan y se asignan solas.

En la carta salen marcadas como "Foto ilustrativa / Symbolbild". Cuando el restaurante haga la foto real desde el panel, la etiqueta desaparece.
